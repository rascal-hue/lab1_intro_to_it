Словесный алгоритм программы №1:
1.	Начало программы.
2.	Объявление шаблонного класса SafeArray с полями: указатель на данные data и размер size.
3.	Конструктор: выделяет динамическую память под массив размера n.
4.	Деструктор: освобождает выделенную память.
5.	Перегрузка оператора []: проверяет, не вышел ли индекс за границы [0, size-1]. Если вышел — выводит сообщение об ошибке и завершает программу.
6.	Функция main:
	Ввод целого числа n — размера массива.
	Создание объекта SafeArray<int> arr(n).
	Ввод n элементов массива через перегруженный оператор [].
	Последовательный перебор элементов массива с начала:
	Если текущий элемент больше 0 → вывести «Polozhitelnoe ranshe» и завершить программу.
	Если текущий элемент меньше 0 → вывести «Otricatelnoe ranshe» и завершить программу.
	Если после просмотра всех элементов ни одно условие не сработало → вывести «Net polozhitelnyh i otricatelnyh chisel».
7.	Конец программы.


Словесный алгоритм программы №2:
1.	Начало программы.
2.	Определение структуры Animal с полями: age (целое), weight (вещественное).
3.	Определение структуры Result с полем monthlyReduction (вещественное).
4.	Функция calculateReduction:
	Принимает массив структур Animal и его размер n.
	Создаёт переменную r типа Result, инициализирует r.monthlyReduction = 0.
	Запускает цикл по всем животным от 0 до n-1:
	Если возраст животного от 6 до 8 лет включительно И вес больше 7 кг:
	Увеличивает r.monthlyReduction на 0.125 * 30 (что равно 3.75 кг).
	Возвращает структуру r.
5.	Функция main:
	Объявляет целочисленную переменную n.
	Вводит значение n с клавиатуры.
	Создаёт массив animals размером 100 (максимальный запас).
	В цикле от 0 до n-1 вводит для каждого животного возраст и вес.
	Вызывает функцию calculateReduction(animals, n), сохраняет результат в res.
	Выводит значение res.monthlyReduction и слово «kg» на экран.
6.	Конец программы.
